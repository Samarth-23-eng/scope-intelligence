# Roadmap

The roadmap is directional rather than a promise. Priorities are refined
through issues, contributor interest, security review, and real-world testing.

## 0.1 — Public foundation

- [x] Evidence-normalized collection pipeline
- [x] Hybrid retrieval and citation-bound claims
- [x] Relationship fusion and graph exploration
- [x] Investigation workbench
- [x] Monitoring, verification, and situation timeline
- [x] Provider-neutral encrypted BYOK model gateway
- [x] Public contribution and security foundation
- [ ] Expanded installation smoke tests across Windows, macOS, and Linux

## 0.2 — Portability and operator control

- [ ] JSON, CSV, GraphML, and evidence-bundle exports
- [ ] Import/export of company monitoring configurations
- [ ] Source-adapter SDK and contract test suite
- [ ] Per-source budget controls in the dashboard
- [ ] Collection replay from stored fixtures
- [ ] Better report templates and theme customization

## 0.3 — Evaluation and intelligence quality

- [ ] Agent evaluation datasets and regression dashboard
- [ ] Claim-level hallucination and citation-quality benchmarks
- [ ] Relationship precision/recall evaluation tooling
- [ ] Model cost, latency, and token telemetry
- [ ] Operator comparison of model/provider configurations

## 0.4 — Team deployment

- [ ] Authentication and role-based workspace access
- [ ] Project and tenant boundaries
- [ ] Audit-log export
- [ ] PostgreSQL backup and restore workflows
- [ ] Deployment hardening behind a reverse proxy
- [ ] Documented horizontal worker model

## Contribution priorities

High-value community contributions include official public-source adapters,
accessibility fixes, tests, retrieval evaluation, documentation translations,
source reliability rules, and safe export formats.

Open an issue before beginning a major roadmap item.
