# Ethical Use

Scope Intelligence is built for responsible research using public information.

## Acceptable use

- Competitive and market research using lawfully accessible sources.
- Monitoring a company's public websites, feeds, releases, repositories, job
  postings, and official channels.
- Defensive security and due-diligence work performed with proper authority.
- Academic research with appropriate review, minimization, and retention rules.

## Prohibited project features

Contributions must not:

- steal or replay credentials;
- automate private accounts;
- bypass authentication, CAPTCHAs, paywalls, or technical access controls;
- facilitate stalking, doxxing, discrimination, intimidation, or targeted harm;
- collect sensitive personal data without a lawful, documented purpose;
- conceal provenance or falsely present inference as verified fact.

## Operator responsibilities

Operators are responsible for applicable law, contracts, source terms, robots
directives, rate limits, data protection, retention, and secure handling.
Public availability does not automatically make every collection or use
appropriate.

Use the minimum data needed for a defined research question. Prefer official
APIs and feeds. Keep experimental sources disabled by default. Delete data that
is no longer required.

## Intelligence integrity

- Distinguish fact, inference, prediction, and unresolved gaps.
- Preserve source URLs, timestamps, and evidence excerpts.
- Review contradictions and low-diversity claims.
- Do not treat an AI-generated statement as evidence.
- Provide a human review path for consequential decisions.

## Reporting misuse

Do not publish private target data in an issue. Report security vulnerabilities
through [SECURITY.md](../SECURITY.md). Report community misconduct under the
[Code of Conduct](../CODE_OF_CONDUCT.md).
