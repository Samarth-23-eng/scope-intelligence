# Support

Scope Intelligence is maintained by an open-source community.

## Where to ask

- **Setup problem or reproducible bug:** open a bug report.
- **New capability or source:** open a feature or source-adapter request.
- **Usage question:** use GitHub Discussions when available.
- **Security vulnerability or exposed credential:** follow
  [SECURITY.md](SECURITY.md) and do not post details publicly.

Before requesting help, search existing issues, review
[docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md), and collect sanitized logs.
Remove tokens, cookies, personal information, private target data, tunnel URLs,
and internal hostnames before posting.

Community support is best-effort. Please include the operating system,
deployment method, relevant component versions, expected behavior, actual
behavior, and the smallest safe reproduction.
